# NOUVURA — Portfolio Website

A self-contained, responsive static portfolio built for GitHub Pages.

## Included
- French as the default language, with English and Arabic language switching.
- Arabic right-to-left layout support.
- Responsive layout for mobile, tablet and desktop.
- Animated hero composition, scroll reveals, service illustrations, project filters and hover states.
- Contact form that prepares a WhatsApp message for the visitor to review and send.
- Direct links to phone/WhatsApp, email, YouTube and Facebook.
- The provided `logo.png` is included in `assets/`.

## Preview locally
Open `index.html` in a browser. For best results, use a local static server, but no build step is required.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `nouvura-portfolio`.
2. Extract this ZIP on your computer.
3. Upload **the contents of this folder** to the repository root: `index.html`, `styles.css`, `app.js`, `assets/`, and `README.md`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The public URL will appear in the same Pages section.

## Before publishing
- The project gallery currently uses original CSS-made concept studies. They are labelled as concept work and should be replaced or supplemented with real projects when available.
- Confirm the Facebook page URL and other public social destinations.
- The WhatsApp link is configured for the provided number using Algeria's country code.
- The page uses Google Fonts when internet access is available; system sans-serif fallbacks are included.
- The site is static and does not need a server-side backend. The contact form opens WhatsApp; it does not send a message automatically.
